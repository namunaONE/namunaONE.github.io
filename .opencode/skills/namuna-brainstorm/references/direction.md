# Namuna Flow — custom run direction

Use only when the user explicitly asks for custom ("custom", "derive it", "bespoke", "no theme", "a world of its own"). This replaces the draw, the shapes, layout.md, genre file, and composition/fold rules. The Floor, the gates, and the sweep still hold.

## Custom method

1. **Unique is specific.** Every large decision belongs to this client: its subject, its place, its materials, its numbers, the way its people talk. Put the nearest competitor's name on the page; if it still works, keep going.
2. **Clean is exact, not empty.** A system you can see: a few type sizes far apart, one spacing rhythm, edges that line up. Nothing on the page that is not doing a job. On every screen, one thing strong enough to be its reason.
3. **Full is the floor.** A custom page is a whole site, not a hero and a sampler: everything the client has to say and show, from first screen to footer — usually six to nine sections, each built around something worth looking at (the product working, a photograph, real facts set large).
4. **Let the idea run the page.** One thought the whole page grows from, true of this client and no other. It can live in the type, the color, the structure, the motion, the way the product is shown, or something the visitor does.
5. **Silence never takes this route.** Custom is only chosen when explicitly named.
