# Namuna Flow — macrostructures (21 page shapes)

Load only the file you pick during `namuna-brainstorm` Step 3. A macrostructure is a material, not a plan — it never says what a page contains or in what order.

1. **Long Document** — essay, report, whitepaper; type-led, facts set large
2. **Letter** — personal, direct address; one column, warm
3. **Index-First** — directory, catalog, library; search + list up front
4. **Manifesto** — belief-led; bold type, short sections, strong CTA
5. **Portfolio** — work-led; projects as the hero, case studies below
6. **Product** — feature-led; demo/screenshot central, pricing near CTA
7. **Landing** — conversion-led; hero → proof → features → CTA band
8. **Dashboard** — data-led; metrics grid, recent activity, quick actions
9. **Atlas** — map-led; geography first, data table secondary (Namuna One atlas uses this)
10. **Chronology** — timeline-led; events in order, milestones marked
11. **Glossary** — definition-led; terms + definitions, searchable
12. **Compare** — two-column; before/after, us/them, pros/cons
13. **Switcher** — dual-view; client view vs your view, toggle between
14. **Pinned** — sticky section; one element stays while story scrolls past
15. **Wizard** — step-led; progress bar, one question at a time
16. **Gallery** — image-led; grid of works, lightbox detail
17. **Editorial** — section-led; pull quotes, sidebars, varied rhythm
18. **Onboarding** — tutorial-led; first-time user, guided steps
19. **Status** — incident-led; current state, history, what to do
20. **Directory** — person/place-led; cards with contact, map, hours
21. **Reference** — doc-led; API or data reference, search + copy examples

**Namuna One uses:** Atlas (homepoint page), Portfolio (projects), Editorial (method/about).
